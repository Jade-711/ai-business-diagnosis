网站发布源码与扣子平台发布是两个独立动作。线上状态接口核实网站绑定的是用户给定的 Main_agent；它并不证明 `site/workflow/` 中的每项后续修订已经发布到该 Main_agent。因此本仓库将原画布导出设为查阅主入口，没有用维护稿替换它。

扣子历史界面显示最新已发布 v0.0.16（2026-11-04），当前画布显示尚未发布编辑；本次没有点击扣子发布，也没有修改网站线上版本或环境变量。适配层提供既有无密钥源文件，没有导出平台在线保存的 Bearer 密钥，也未重新执行真实模型验收。

## 为公开分享做的变换

1. 新建独立源码快照，不复制原 `.git` 历史、环境文件、线上数据库或运行日志。
2. 工作流导出移除 `_temp` 编辑器缓存，其中包含头像、用户资料及带签名的图标 URL；保留实际节点、提示词、参数、输出和连线。
3. 资源服务和评测资源服务域名替换为保留的 `.example` 域名；原站公开体验链接保留。
4. Sites 项目标识替换为 `REPLACE_WITH_YOUR_SITES_PROJECT_ID`，环境变量示例不含密钥。工作流原始 ID 作为引用来源保留；自行部署时必须替换为自己的 ID。
5. 根目录构建只打包网站资产，不运行会重新生成工作流的历史完整构建脚本。
6. README 与运行说明按本次实际读取的代码和发布状态更新。

这些变换不回写生产环境。
